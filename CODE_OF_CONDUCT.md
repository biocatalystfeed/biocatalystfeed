# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, no harassment or personal attacks. Discussions about
specific companies or drugs must not include market manipulation, non-public information, or
investment solicitation.

Report unacceptable behaviour privately through the repository's
[private vulnerability/report form](https://github.com/biocatalystfeed/biocatalystfeed/security/advisories/new)
(mark the title "Conduct"); maintainers will review every report and keep it confidential.
